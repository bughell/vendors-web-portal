# Портал подрядчика

Рабочая стартовая страница на React + TypeScript + Vite. Требуется Node.js 24.

```bash
cd /workspace/vendors-web-portal
npm ci --cache=/workspace/.cache/npm
npm run dev
```

Dev-сервер слушает порт **5173** на всех интерфейсах. Открывайте страницу через
поддерживаемый вашей средой доступ к этому порту. Открытие `index.html` двойным
щелчком без сервера не запускает TypeScript-приложение. В режиме Cloud Environment
Onboarding веб-предпросмотр не поддерживается; работа страницы проверяется
локальными HTTP-запросами и браузерными тестами. Публикация облачной среды
сохраняет её состояние и не является размещением сайта в Интернете.

```bash
npm run build    # проверка типов и production-сборка в dist/
npm run preview  # проверка готовой сборки на порту 4173
```

Готовая **`dist/index.html`** — самостоятельная страница со встроенными стилями,
JavaScript и иконкой. Её можно скачать и открыть в Chrome или Edge без установки
Node.js и запуска сервера. `dist/portal.html` содержит такую же страницу для
совместимости с прежней ссылкой. Доступность локального хранилища зависит
от настроек браузера.

Исходный **`index.html` в корне проекта** запускается через Vite. Если просмотр
открывает его как `file:///…/index.html`, браузер пытается найти `/src/main.tsx`
и `/favicon.svg` в корне диска. Это не проблема CORS-настроек приложения:
для исходника нужен работающий dev-сервер, обрабатывающий TypeScript.
Для просмотра одного HTML-файла используйте именно `dist/index.html`;
отключать защиту браузера не требуется.

## Что работает

- Страница заявки с данными акта, договора, суммы и банковских реквизитов.
- Выбор файлов и drag-and-drop: PDF, DOCX, XLSX и XLS; до 25 МБ на файл,
  до 10 файлов и до 100 МБ на заявку.
- Проверка обязательных полей и просмотр введённых данных.
- Сохранение, повторное открытие и удаление черновиков вместе с файлами
  в IndexedDB браузера. Черновики изолированы по origin (адресу и порту).
- Адаптивная мобильная версия.

Это локальная демонстрация. Серверное хранение, авторизация и обмен с 1С
не подключены; данные остаются в текущем браузере. Не используйте демо для
реальных платёжных документов. Проверка расширений файлов на клиенте не заменяет
серверную проверку содержимого и антивирусную обработку.

## Дальнейшая интеграция

У пользователя платформа 1С:Предприятие 8.3, Бухгалтерия предприятия и зарплатная
конфигурация. Публичных HTTP/SOAP-сервисов нет; наличие внутренних неизвестно.
Планируется серверный обмен с внутренним HTTP-сервисом через VPN и HTTPS.
Редакции конфигураций, адреса, контракт и аутентификацию требуется определить.
Учётные данные 1С не должны находиться в браузере или в переменных VITE_*.
